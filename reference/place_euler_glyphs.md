# Pack equal circular glyphs inside exclusive regions.

Pack equal circular glyphs inside exclusive regions.

## Usage

``` r
place_euler_glyphs(
  set_names,
  shape,
  h,
  k,
  a,
  b,
  phi,
  width,
  height,
  side,
  container_h,
  container_k,
  container_width,
  container_height,
  n_vertices,
  region_names,
  counts,
  arrangement,
  radius,
  gap,
  seed,
  max_attempts,
  obstacle_h,
  obstacle_k,
  obstacle_width,
  obstacle_height,
  precision
)
```
