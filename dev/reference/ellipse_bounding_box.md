# Bounding box of a vector of rotated ellipses.

Bounding box of a vector of rotated ellipses.

## Usage

``` r
ellipse_bounding_box(h, k, a, b, phi)
```

## Arguments

- h, k:

  ellipse center coordinates

- a, b:

  semi-major and semi-minor axes

- phi:

  rotation of the semi-major axis, in radians
